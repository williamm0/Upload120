# Upload120

Upload120 is a desktop upload helper for TikTok Studio on Windows and Mac.

Website: https://upload120.com/

## What It Does

- Runs the Studio Method on a supported video, then you upload the finished file through TikTok Studio.
- Uses Discord login for access and quota.
- Free is 1 video a day, up to 40 MB and 1 minute. A confirmed referral unlocks videos up to 30 minutes.
- One-time Pro passes, charged in GBP: Day £0.99, 7 Day £1.99, 30 Day £4.99, and 90 Day £11.99.
- Shows queue status, referral quota, and upload guidance on the website.
- Provides a Chrome extension for the TikTok Studio upload flow on desktop Chrome.
