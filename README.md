# Upload120

Upload120 is a PC upload helper for TikTok Studio.

Website: https://upload120.com/

## What It Does

- Prepares supported video files for TikTok Studio uploads on PC.
- Uses Discord login for access and daily quota.
- Shows upload status, referral quota, and upload guidance on the website.
- Provides a Chrome extension for the TikTok Studio file picker.

## Notes

Upload120 is privately hosted on Cloudflare. This GitHub page exists only so search engines can find the official website.

Upload120 is independent and is not affiliated with, endorsed by, or sponsored by TikTok.
